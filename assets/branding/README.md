# YUB WPanel branding assets

`yub-wpanel-logo-master.png` is the high-resolution generated master. The
application uses the optimized 180×180 copy at `static/logo.png`.

Design intent:

- network-orchestration nodes above a three-column server stack;
- deep navy background with cyan, azure, and restrained teal accents;
- text-free silhouette that remains recognizable at 32–64 pixels;
- transparent canvas outside the rounded application tile.

Generation prompt:

> Original geometric emblem for YUB WPanel combining an abstract Y-shaped
> network fork with a subtle W formed by three stacked server panels. Crisp,
> minimal, vector-like mark for a WordPress server-management dashboard; deep
> navy tile, cyan and azure mark, restrained teal status accents; no text,
> mockup, 3D treatment, watermark, or resemblance to known trademarks.
